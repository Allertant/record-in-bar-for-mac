# 遮罩层二次确认

## 架构模式

三层结构：状态变量 → overlay 条件渲染 → `ConfirmActionPage` 组件。

---

## 1. `ConfirmActionPage` 组件

纯 UI 组件，不依赖任何 ViewModel，通过闭包回调通信，可跨场景复用。

```swift
ConfirmActionPage(
    icon: "trash",             // SF Symbol 名称
    iconTint: .red,            // 图标颜色
    title: "记录标题",          // 确认目标标题
    message: "删除后无法恢复？", // 确认提示语
    confirmLabel: "确认删除",   // 确认按钮文字
    confirmRole: .destructive, // 按钮角色（可选）
    onCancel: { /* 取消 */ },
    onConfirm: { /* 执行 */ }
)
.background(.ultraThinMaterial) // 毛玻璃遮罩
```

文件位置：`Packages/RecordInBarKit/Sources/RecordInBarKit/Presentation/Components/ConfirmActionPage.swift`

---

## 2. 使用模式

### 状态

```swift
@State private var showDeleteConfirmation = false
```

### 触发

```swift
Button { showDeleteConfirmation = true } label: {
    Image(systemName: "trash")
}
```

### 遮罩层

用 `.overlay` + 状态条件判断渲染：

```swift
.overlay {
    if showDeleteConfirmation {
        Color.black.opacity(0.25)
            .ignoresSafeArea()
            .onTapGesture { showDeleteConfirmation = false }

        ConfirmActionPage(
            icon: "trash",
            iconTint: .red,
            title: "目标标题",
            message: "确认提示语",
            confirmLabel: "确认操作",
            onCancel: { showDeleteConfirmation = false },
            onConfirm: {
                showDeleteConfirmation = false
                // 执行操作
            }
        )
        .background(.ultraThinMaterial)
        .transition(.opacity)
    }
}
```

---

## 3. 关键设计点

- `ConfirmActionPage` 是纯 UI 组件，通过闭包回调通信，可跨场景复用
- `.background(.ultraThinMaterial)` 提供毛玻璃遮罩效果
- 先清状态 `showDeleteConfirmation = false` 再执行操作，防止重复触发
- 状态驱动：状态为 `false` 时遮罩自动消失，无需手动管理动画
- 当 body 过长导致编译器类型检查超时时，将 overlay 内容提取为 `@ViewBuilder` 计算属性
